# Tessellate Embedding v2

Reference implementation and inference utilities for the Tessellate Embedding v2 text embedding model.

**Repository Status:** Released (v2.0.3, published 2026-05-18)

## Contents

- `src/tessellate/encoder.py`
- `src/tessellate/pool.py`
- `requirements.txt`

## Quick start

```bash
pip install -r requirements.txt
python -m tessellate.encoder --text "hello world"
```
